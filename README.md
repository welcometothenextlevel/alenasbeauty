# Alena’s Beauty · Fey (VD)

One-page site for Alena’s Beauty, a nail and beauty studio run by Alena Hudáčová Gehri at Route d’Echallens 4, 1044 Fey. The site is written in French, as static HTML, CSS and JS, with no build step.

- `index.html`: the whole page
- `assets/css/style.css`, `assets/js/main.js`: styles and behaviour (GSAP + ScrollTrigger vendored in `assets/vendor/`)
- `assets/img/`: WebP photos, the vectorised logo (`logo-mark.svg`) and the line art from the logo (`line-art.svg`)
- `assets/video/`: Instagram reels, muted and optimised for the web
